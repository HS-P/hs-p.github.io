# Hansol Park Academic Homepage

Personal academic homepage for <https://hs-p.github.io/>.

## Structure

- `/` — research-first homepage with current focus, graduate work, undergraduate foundations, outputs, and experience.
- `/projects/` — Graduate and Undergraduate project groups.
- `/blog/` — preserved Sol's Diary archive, intentionally removed from the main navigation.
- `/cv/` — concise academic CV.

The site is a small Jekyll project using custom layouts and CSS for build stability on GitHub Pages.
