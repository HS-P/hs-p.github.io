# Hansol Park Academic Homepage

Personal academic homepage for <https://hs-p.github.io/>.

## Structure

- `/` — academic homepage with papers, awards, selected projects, and experience.
- `/projects/` — full project list.
- `/blog/` — preserved Sol's Diary posts.
- `/cv/` — concise academic CV.

The site is a small Jekyll project using custom layouts and CSS for build stability on GitHub Pages.
